# 점자메뉴판 보유 매장 찾기

빌드 없이 dist를 제공하는 정적 웹 앱. Sites 이외의 정적 호스팅으로 이전할 수 있습니다.

## 데이터 운영
- 원본: Google Sheets `1t0MlHxpVzZkidUJoTkGHoJqnvio1u7oCn85h1rUUdgY`, `매장 관리` 탭 A:S.
- `사이트 공개용` 탭의 A2 FILTER 수식이 공개 여부=공개 AND 현재 비치 상태=비치 중인 매장만 출력합니다. 공개용 탭을 직접 수정하지 않습니다.
- 공개 탭에는 최종 확인일과 공개 여부 등 관리 열을 포함하지 않습니다. 공개된 CSV의 데이터는 누구나 읽을 수 있습니다. 원본 파일의 공유 권한과 웹 게시 권한은 별개입니다.
- S열 `목록용 지역`은 예를 들어 `경기 군포시 산본동`으로 입력합니다. 비어 있으면 주소에서 시·도와 시·군·구까지만 사용합니다. 도로명 주소로 동을 추정하지 않습니다.
- `dist/public-feed.json`에 Google이 발급한 단일 탭 CSV 게시 URL을 보관합니다. 다른 호스팅으로 이전해도 이 설정과 파일을 그대로 사용합니다.
- 페이지를 열거나 새로고침할 때 설정과 CSV를 가져옵니다. 화면을 켜둔 동안 실시간 갱신하지 않습니다. Google 게시 캐시로 수 분 지연될 수 있습니다.
- 헤더만 있는 정상 CSV는 0개 매장을 표시합니다. 네트워크/스키마 오류는 재시도 화면을 표시합니다. 이전 스냅샷으로 되돌리지 않습니다(비공개 전환한 매장 재노출 방지).
- 공개 여부를 비공개로 바꾸거나 비치 상태를 변경하면 게시 갱신 후 다음 조회부터 제외됩니다. 이미 내려받은 정보의 회수는 보장할 수 없습니다.
- 머리글 이름·열 순서는 코드의 HEADERS와 일치해야 합니다. 운영 시 기존 열 이름을 바꾸거나 공개용 탭에 열을 삽입하지 않습니다.
- 새 매장에는 고유 매장 ID(영문/숫자/밑줄/하이픈), 매장명, 주소를 입력합니다. 중복 ID나 깨진 행이 있으면 피드 검증이 실패합니다.

## 기능 및 검토
- 직접 검색 → 지역 선택 → 목록/상세 순서. 전화, 카카오·네이버 외부 길찾기, 주소 복사.
- 제목·폼·링크, 상태 알림, 목록 복귀 초점, 글자 크기·고대비 설정.
- 매장 상세·오류 제보·이용 안내는 상단 돌아가기 영역만 스크롤 시 고정합니다. 제보 하단에 돌아가기 링크를 중복 제공하지 않습니다. ResizeObserver가 확대·줄바꿈에 따른 고정 영역 높이를 반영해 초점 이동 시 사용할 스크롤 여백을 갱신합니다.
- 오류 종류와 자세한 내용을 필수로 입력한 뒤 메일로 제보하기를 누르면 mailto 링크로 바로 메일 앱을 엽니다. 중간 확인 화면은 없습니다. 복사 버튼은 같은 화면에서 선택적으로 사용할 수 있습니다. 수신 주소는 sonkkeutgp@gmail.com이며, 매장명·ID·오류 종류·내용을 채웁니다. 이용자가 메일 앱에서 전송해야 발송됩니다. 메일 앱이 없는 경우 내용을 복사할 수 있습니다. 발송 확인·서버 접수 기능은 없습니다.
- 실제 VoiceOver/Safari, TalkBack/Chrome 테스트 및 길찾기/출입구 위치 확인은 별도 필요합니다.
- AI API, API 키 또는 사용자별 Google 로그인이 데이터 읽기에 필요하지 않습니다.
